# 🛡️ SafeSignal

SafeSignal is a web-based safety awareness application designed to help users stay alert to their surroundings while using their phones.

This project demonstrates how motion detection and real-time alert logic can be implemented using JavaScript and browser APIs to simulate a simple safety-focused application.

---

## 🚨 Purpose

Distraction from smartphones can lead to everyday accidents, such as walking into objects or failing to notice surroundings. SafeSignal is a prototype that explores how software can help improve awareness through motion and orientation detection.

This project was built to strengthen front-end development skills while applying real-world problem-solving concepts.

---

## 💡 Features

- 📱 Device motion detection  
- 📐 Phone tilt detection (looking down awareness)  
- ⚠️ Visual warning alerts  
- 🚨 Emergency alert button (simulation)  
- 🔔 Real-time event-based notifications  

---

## ⚙️ How It Works

SafeSignal uses built-in browser APIs:
- **DeviceMotion API** to detect movement  
- **DeviceOrientation API** to detect phone tilt  

When certain movement or tilt thresholds are exceeded, the app displays a warning message to alert the user.
The emergency button simulates a quick-access alert feature.
For best results, test on a mobile device and allow motion permissions when prompted.
